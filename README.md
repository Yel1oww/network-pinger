# Network Pinger

A fast and efficient network scanner in Python that pings all hosts in a given subnet and reports which IP addresses are active. Built using asyncio and aioping for concurrency and speed.

# Features

Asynchronously ping all hosts in a specified subnet.

Display live progress with a visual progress bar.

Handles timeouts gracefully.

Lists all active IP addresses at the end.

Simple and user-friendly command-line interface.

# Installation

Clone the repository:

git clone https://github.com/Yel1oww/network-pinger
cd network-pinger

Install dependencies:

pip install aioping

# Usage

Run the script:

python network_scanner.py
